# 글로비와 영어 세계 여행 (체험판)

초등학생 대상 방과후 영어 프로그램 **「세상을 교실로 가져오다」**의 AI 활용 차시를 미리 체험해 보는 웹 페이지예요.
지구본 친구 **글로비**와 영어로 역할극을 하고, 미션을 깨면 여권에 도장을 모아요.

> 이 페이지는 **체험판**이에요. 글로비의 대답과 피드백은 모두 미리 만든 예시예요.
> AI나 외부 서버에 연결하지 않고, 입력한 내용은 어디에도 전송되지 않아요.

## 들어 있는 활동

| 활동 | 수업 차시 | 하는 일 |
| --- | --- | --- |
| Travel Mission | 11~12차시 | 입국 심사, 가방 분실, 음식 주문, 알레르기, 길 찾기 미션을 글로비와 영어 역할극으로 해결해요 |
| My Voice | 3~4차시 | 자기소개를 쓰고, 원어민 발음으로 들어 보고, 피드백을 받아 다시 말해요 |
| Presentation Coach | 23~24차시 | 발표문 표현 제안을 받고, 고칠지는 학생이 직접 정해요. 내 영어 문장과 AI 번역도 비교해요 |
| Word Book | 29~30차시 | 해외 친구와 이야기할 주제별 단어장을 보고 퀴즈를 풀어요 |

- 학년군(3~4학년 / 5~6학년)을 고를 수 있어요.
- 시작 전에 "AI 사용 약속" 세 가지에 체크해요(개인정보 입력 금지, 이상하면 알리기, AI도 틀릴 수 있어요).
- 도장 기록은 쓰는 사람의 브라우저에만 저장돼요.

## GitHub Pages로 공개하기

1. GitHub에서 새 저장소를 만들어요(예: `globi-english-demo`, Public).
2. 이 폴더의 `index.html`과 `README.md`를 저장소에 올려요(**Add file → Upload files**).
3. 저장소의 **Settings → Pages**로 가서 **Source: Deploy from a branch**, **Branch: main / (root)**를 고르고 저장해요.
4. 1~2분 뒤 `https://<계정이름>.github.io/<저장소이름>/` 주소로 열려요.

## 반응 확인하기 (선택)

`index.html`의 맨 아래 스크립트 첫 부분에 있는 `CONFIG`만 바꾸면 돼요.

```js
const CONFIG={
  formUrl:'',      // 관심 신청·의견 구글 폼 주소
  goatcounter:''   // 방문자 집계 GoatCounter 코드
};
```

- **formUrl**: 구글 폼을 만들고 공유 주소(`https://forms.gle/...`)를 넣으면 "관심 있어요 · 의견 남기기" 버튼이 나타나요.
- **goatcounter**: [GoatCounter](https://www.goatcounter.com/)에서 무료 계정을 만들고 코드(예: `globi-demo`)를 넣으면 방문자 수를 볼 수 있어요. 쿠키를 쓰지 않는 집계 도구예요.

## 알아 두세요

- "듣기" 소리는 기기에 들어 있는 음성 읽기 기능이 내요. 기기마다 목소리가 다르고, 낯선 외래어는 잘못 읽을 수 있어요.
- 말로 입력하기(음성 인식)는 지원하는 브라우저(크롬 등)에서만 보여요.
- 마스코트 글로비는 이 프로그램을 위해 새로 그린 캐릭터예요.
